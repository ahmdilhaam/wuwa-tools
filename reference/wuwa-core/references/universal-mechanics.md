# Universal Mechanics

**Game Version:** 3.4 | **Source:** Chasey's WW Character Build Guide | **Last Updated:** June 26, 2026

---

## ELE+ELE vs ELE+ATK on 3-Cost Echoes

Only 1–3% difference between using two element DMG bonus vs one element + one ATK% on 3-cost echoes.

**Practical rule:** Pick whichever combination has better substats. Never sacrifice good substats to chase the "correct" main stat combo if the difference is this small.

Exception: some characters have specific guidance (e.g. Jinhsi with Ages of Harvest sig uses 1× Spectro DMG + 1× ATK%).

---

## Echo Configuration: 43311 vs 44111

**43311** beats 44111 in most cases.

**44111** only becomes better when the character has many sequences/dupes — the extra 4-cost slot gives more value when multipliers are already high.

Default recommendation: always go 43311 unless the character guide specifically notes otherwise.

## Forte Tree Priority

Based on how much the skill share (passive skill amplification) is worth:

| Skill Share % | Recommended Forte Level |
|---|---|
| 1–9% | Lv1 or Lv6 |
| ≤10% | At least Lv6 |
| 10–14% | Lv6–8, or max if budget allows |
| ≥15% | Lv10 (max) |

---

## Signature Weapon Value

Signature weapons average **10–20% more damage** over the best F2P alternative.

- **Main DPS:** Worth pulling for
- **Supports/Sub-DPS:** Luxury — strong F2P options usually exist

---

## Energy Recharge Thresholds

ER thresholds vary by character and team. Key rules:
- Characters using Tidebreaking Courage set (e.g. Brant) need at minimum the ER threshold to activate the 5pc bonus
- Supports in Moonlit Clouds need enough ER to Outro reliably each rotation
- Always check the character-specific entry for their ER target

## Notes on Off-element Sets

Some characters use off-element sets for their 2pc bonus (e.g. Moonlit Clouds for the ATK buff on Outro). Always check the character's echo set recommendation — it may not be their element's native set.
