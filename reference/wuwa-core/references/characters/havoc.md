### Taoqi — Support (Havoc)
**Source:** 12th Harbinger — https://www.youtube.com/watch?v=AGXUNsgOCjk
**Prydwen page last updated:** Patch 2.3 (build/calcs), Jan 6 2026 (profile)
**Rarity/Weapon:** 4★ Broadblade
**Tier:** T4 (both Tower of Adversity and Whimpering Wastes)

- **Echo (Option 1 — Standard):** Bell-Borne Geochelone OR Fallacy of No Return | 5pc **Rejuvenating Glow**
  - 2pc: Healing +10% | 5pc: Heal ally → whole team ATK +15% for 30s
- **Echo (Option 2 — Moonlit):** Impermanence Heron | 5pc **Moonlit Clouds**
  - 2pc: ER +10% | 5pc: Outro → next char ATK +22.5% for 15s
  - Impermanence Heron: Use right before Outro, swap-cancel → incoming char gets 12% DMG Bonus + 22.5% ATK
- **Echo main stats:** 4-cost DEF% | 3-cost ER% > DEF% | 3-cost ER% > DEF% | 1-cost DEF% | 1-cost DEF%
- **Weapons:**
  - BiS: Discord R5 (ATK 337, ER 51.8%) — cuts rotation time dramatically
  - 2nd: Dauntless Evernight R5 (ATK 337, DEF 61.5%) — free exploration reward
- **Stat targets (Level 90, S6):**
  - HP: 15,000+ | DEF: 1,150+ | ATK: 1,800–2,200+
  - CRIT Rate: 60–80%+ | CRIT DMG: 210–260%+
  - ER: 100%–126%+ (Moonlit at S5: none needed; Carlotta+Shorekeeper: ~126%)
  - Havoc DMG Bonus: 30–60%+
- **Substats priority:** ER% (until breakpoint) > CRIT Rate / CRIT DMG > DEF% > flat DEF
- **Forte/Skill priority (Support):** Forte Circuit > Res. Skill > Res. Liberation > Basic Attack > Intro Skill
- **Forte/Skill priority (DPS):** Res. Liberation > Forte Circuit > Res. Skill > Basic Attack > Intro Skill
- **Outro:** 38% Resonance Skill DMG Deepen for 14s
- **Sequences:**
  - S1: Forte shields +40% (minor) | S2: Ult CRIT Rate/DMG +20%/+20% (minor) | S3: Shield duration 30s (QoL)
  - S5: Forte DMG +50% + restores 20 Resonance Energy on hit (significant)
  - S6: Basic/Heavy ATK DMG +40% while shield active
  - *Overall: Poor sequence value — not worth investing heavily*
- **Teams:**
  - **Carlotta Nuke Team:** Carlotta + Taoqi + Shorekeeper/Verina
  - **Jinhsi Nuke Team:** Jinhsi + Taoqi + Verina (Verina needed for Coordinated Attack Forte stacks)
- **Rotation:**
  - Pre-rotation (no Discord): Basic P1–P3 to build Concerto
  - Main: Intro → Timed Counter ×3 → Ultimate → Basic P1–P4 → Skill → Outro
  - With Discord: skip most/all pre-rotation basics
- **Notes:**
  - Kit is fundamentally flawed for meta use. Forte Circuit requires getting hit (unreliable). Heavy Attack wait time (3s) is slow. One of the longest support rotations.
  - Single niche: 38% Skill DMG Deepen Outro for Jinhsi/Carlotta. Still viable for clearing all content in those teams.
  - Compared to Lumi (same Outro but 10s duration) and Zhezhi (premium 5★ with Coord Attacks).
  - Bottom-tier but not unplayable — niche pick for big nuke teams only.

### Danjin — Hybrid Sub-DPS / Main DPS (Havoc)
**Source:** Saintontas — https://www.youtube.com/watch?v=dPiRmXwCL9k
**Prydwen page last updated:** Patch 2.2 (build/calcs), May 24 2026 (profile)
**Rarity/Weapon:** 4★ Sword
**Tier:** T3 (both ToA and WW)

- **Echo (Hybrid BiS):** Impermanence Heron / Lorelei / NM: Impermanence Heron | 5pc **Moonlit Clouds** (budget) OR 5pc **Midnight Veil** (endgame: 5★ weapon + 9–10 CRIT substats)
- **Echo (DPS):** Dreamless | 5pc **Havoc Eclipse** (Havoc DMG +10%, ramp to +40% total after 4 hits)
- **Echo main stats:** 4-cost CRIT DMG > CRIT Rate | 3-cost Havoc DMG | 3-cost Havoc DMG | 1-cost ATK% | 1-cost ATK%
- **Weapons:**
  - BiS: Blazing Brilliance R1 (105.7%) — CRIT DMG + ATK% + 56% Skill DMG
  - 2nd: Red Spring R1 (100.3%) — ATK% + CRIT Rate + Basic ATK DMG
  - 3rd: Emerald of Genesis R1 (100%) — CRIT Rate + ER + ATK%
  - F2P: Commando of Conviction R5 (81.1%) — ATK% on Intro
  - F2P alt: Somnoire Anchor R5 (long field time), Endless Collapse R5 (ER help), Lumingloss R5
- **Stat targets (Level 90, S6):**
  - HP: 16,500+ | DEF: 1,150+ | ATK: 2,000–2,200+
  - CRIT Rate: 60–80%+ | CRIT DMG: 210–260%+
  - ER: 100%–110%+ | Havoc DMG Bonus: 40–70%+
- **Substats priority:** CRIT Rate = CRIT DMG > ATK% > flat ATK > Heavy DMG% > Res. Skill DMG%
- **Forte/Skill priority:** Forte Circuit > Res. Skill > Res. Liberation > Basic Attack > Intro Skill
- **Outro:** 23% Havoc DMG Deepen for 14s
- **Key mechanic:** Danjin spends 3% max HP per Skill hit. Forte Circuit (Chaoscleave) restores ~1/3 max HP. Never dies below 1% from Skill. High-risk high-reward playstyle.
- **Sequences:**
  - S1: ATK +5% per Skill hit on marked enemy (up to 30%) | S2: DMG dealt +20% on Incinerating Will targets — **significant**
  - S3: Liberation DMG +30% | S4: CRIT Rate +15% when Ruby Blossom >60 — **significant**
  - S5: Havoc DMG +15%, +15% more when HP <60% — **significant**
  - S6: Chaoscleave → team ATK +20% for 20s — **game-changing support upgrade**
  - *Best 4★ sequence value in the game*
- **Teams:**
  - **Hybrid for Phrolova:** Phrolova + Cantarella + Danjin
  - **Camellya Hybrid:** Camellya + Danjin + Shorekeeper/Verina
  - **Havoc Rover Hybrid (F2P BiS):** Havoc Rover + Danjin + Shorekeeper/Verina
  - **Main DPS (best):** Danjin + Cantarella + Roccia/Mortefi + Shorekeeper/Verina
  - **Budget Main DPS:** Danjin + Mortefi + Shorekeeper/Verina
- **Rotation (Damage Dealer):**
  Intro → Crimson Erosion I+II → Ult → Carmine Gleam → Basic P2–P3 → Sanguine Pulse I–II–III (×2) → Chaoscleave Full → Scatterbloom → Echo (swap cancel) → Outro
- **Rotation (Hybrid fast):**
  Intro → Crimson Erosion I+II → Ult → Carmine Gleam → Basic P2–P3 → Sanguine Pulse I–II–III → Chaoscleave Partial → Scatterbloom → Echo (swap cancel) → Outro
- **Rotation (Fastest Hybrid):**
  Carmine Gleam → Echo (swap cancel) → Intro → Crimson Erosion I+II → Ult → Carmine Gleam → Basic P2 → Crimson Erosion I+II → Chaoscleave Partial (swap cancel)
- **Notes:**
  - One of the strongest 4★ characters overall. Works at S0 but scales massively with sequences.
  - Primary weakness: constant HP drain; risky against multi-hit enemies.
  - Outclassed by Sanhua as generic Hybrid but better specifically for Havoc DPS (23% Havoc Deepen is more universal than 38% Basic ATK Deepen for characters with mixed damage types like Rover).
  - Must-habit: dodge → immediately cast 2 Skills = mark combo = one of her strongest DPS windows.
  - S6 makes her a genuine support as well as DPS — team ATK buff on Chaoscleave.

### Camellya — Main DPS (Havoc)
**Source:** Braxophone — https://www.youtube.com/watch?v=zof-lMffxrI
**Prydwen page last updated:** Patch 1.4 (review), Patch 2.2 (build/calcs), June 19 2026 (profile)
**Rarity/Weapon:** 5★ Sword
**Tier:** T2 Tower of Adversity | T3 Whimpering Wastes

- **Echo (BiS):** Nightmare: Crownless (12% Havoc DMG + 12% Basic ATK DMG) | 5pc **Havoc Eclipse**
  - Havoc Eclipse: Havoc DMG +10%, ramp to +40% total after 4 hits
  - NM: Crownless animation cancels are crucial to her optimal DPS rotation
- **Echo (Alt):** Mech Abomination | 5pc **Endless Resonance** (ATK ramp from +10% to +30%)
- **Echo main stats:** 4-cost CRIT Rate/CRIT DMG | 3-cost Havoc DMG | 3-cost ATK% ≥ Havoc DMG (Havoc always without Signature) | 1-cost ATK% | 1-cost ATK%
- **Weapons:**
  - BiS: Red Spring R1 (100%) — uniquely powerful for her (Concerto-spend Basic ATK DMG bonus is exclusive to Camellya)
  - 2nd: Emerald Sentence R1 (90.1%) | 3rd: Frostburn R1 (89.5%) | 4th: Everbright Polestar R1 (89.4%)
  - 5th: Emerald of Genesis R1 (89.2%) — best permanent gacha option
  - Battle Pass: Feather Edge R5 (77.8%), Lumingloss R5 (76.8%)
  - Event: Somnoire Anchor R5 (76.3%) — past event
  - F2P: Commando of Conviction R5 (75.3%)
- **Stat targets (Level 90):**
  - HP: 15,000+ | DEF: 1,150+ | ATK: 2,000–2,200+
  - CRIT Rate: 55–80%+ | CRIT DMG: 220–280%+
  - ER: 115%–128%+ (Lynae+Shorekeeper: 115%; Roccia+Shorekeeper: 128%)
  - Havoc DMG Bonus: 70–100%+
- **Substats priority:** ER (until satisfied) > CRIT Rate = CRIT DMG > ATK% > Basic DMG% > flat ATK
- **Forte/Skill priority:** Res. Skill > Forte Circuit > Res. Liberation > Intro Skill > Basic Attack
  - *Basic only worth leveling for White Hair rotation (boss tracking); skip otherwise*
- **Key mechanics:**
  - **Two modes:** White Hair (ground, mobile, single-target focus) / Red Hair/Blossom Mode (airborne, AoE, faster)
  - **Crimson Pistils (0–100):** Consumed by attacks, refilled ONLY by Intro or Forte Skill (Ephemeral). Never start without Intro.
  - **Crimson Buds (0–10):** Generated by consuming Pistils in groups of 10. Each bud consumed = +5% Budding Mode DMG (max +50% extra on top of base +50%).
  - **Forte Skill (Ephemeral):** Costs 70 Concerto Energy. Enters Budding Mode — all attacks deal 50–100% more DMG (depending on Buds).
  - **S6 Perennial:** Extra Ephemeral-equivalent (costs 50 Concerto) adds entire second Budding window.
- **Sequences:**
  - S1: Intro → CRIT DMG +28% for 18s + immune to interrupt during Ephemeral — **high priority**
  - S2: Ephemeral DMG Multiplier +120% — **massive**
  - S3: Liberation +50% + ATK +58% during Budding Mode | S4: Team Basic ATK DMG +25% for 30s on Intro
  - S5: Intro/Outro Multipliers +303%/+68% | S6: Sweet Dream +150% + unlocks Perennial — **game-changing**
- **Teams:**
  - **Best:** Camellya + Lynae + Roccia/Sanhua + Mornye/Shorekeeper/Verina
  - **Alt:** Camellya + Danjin + Cantarella + Shorekeeper/Verina
  - *Sanhua is free and beats Roccia without Signature. Mornye only best with Lynae (Tune Rupture synergy).*
- **Rotation (Standard Red Hair — best loop DPS):**
  Intro → Skill: Crimson Blossom (Echo cancel) → Echo (Dash cancel) → Dash → Heavy Vining Waltz 1–4 (Blazing at 3, Echo cancel after 4) → Echo (Dash) → Dash (Ultimate cancel) → Ultimate → Basic VW1 (Skill cancel) → Skill: Ephemeral → Heavy VW1–4 → Skill: Floral Ravage → Echo (Swap) → Outro
- **Rotation (S6):** Same as above + after Ephemeral: Echo (Dash) → Dash → Basic VW1 → Skill: Perennial → Heavy VW1–4 → Floral Ravage (Swap) → Outro
- **Rotation (White Hair — mobile bosses only, longer):**
  Intro → Skill → Jump → Heavy → Heavy BA4 (hold) → Ultimate → Skill → Jump → Heavy → Heavy BA4 (hold) → BA5 → Outro
- **Notes:**
  - **Rotation inconsistency is her biggest flaw.** Longest DPS rotation (exceeds 15s), so 14s Outro buffs expire before Budding Mode window — the highest-damage portion often has no Outro.
  - Very F2P-friendly: works on free Sanhua/Danjin + Emerald of Genesis.
  - Until S1, Ephemeral is interruptible — a significant frustration against mobile bosses.
  - Still capable of clearing all content. T2/T3 but not unplayable, just inconsistent.
  - NM: Crownless animation cancel timing is the most important mechanical skill for Camellya players.

### Rover (Havoc) — Main DPS / Dual DPS (Havoc)
**Source:** Braxophone — https://www.youtube.com/watch?v=XWTTTdeALKA
**Prydwen page last updated:** Patch 2.2, June 9 2026 (profile)
**Rarity/Weapon:** 5★ Sword (free after Act I Chapter 6)
**Tier:** T3 Tower of Adversity | T4 Whimpering Wastes

- **Echo (BiS):** Dreamless | 5pc **Havoc Eclipse**
  - Dreamless: Within 5s of Ultimate → +50% DMG. Arguably highest-damage Echo in the game. Always swap-cancel immediately.
  - Havoc Eclipse: Havoc DMG +10%, ramp to +40% total after 4 hits
- **Echo main stats:** 4-cost CRIT Rate/CRIT DMG | 3-cost Havoc DMG | 3-cost Havoc DMG > ATK% | 1-cost ATK% | 1-cost ATK%
- **Weapons:**
  - BiS: Red Spring R1 (104.8%) — CRIT Rate + ATK% + Basic ATK DMG
  - 2nd: Blazing Brilliance R1 (104.2%) — CRIT DMG + ATK% + Skill DMG
  - 3rd: Emerald of Genesis R1 (100%) — best permanent gacha
  - F2P: Somnoire Anchor R5 (91.2%), Commando of Conviction R5 (85.3%), Lumingloss R5 (83.6%)
- **Stat targets (Level 90):**
  - HP: 15,000+ | DEF: 1,250+ | ATK: 1,800–2,200+
  - CRIT Rate: 60–75%+ (before S6 buff) | CRIT DMG: 210–260%+
  - ER: 140%+ (all team variants) | Havoc DMG Bonus: 40–70%+
- **Substats priority:** ER (until satisfied) > CRIT Rate = CRIT DMG > ATK% > flat ATK > Basic DMG% > Liberation DMG%
- **Forte/Skill priority (Quick Swap):** Res. Liberation > Forte Circuit > Res. Skill > Basic Attack > Intro Skill
- **Forte/Skill priority (Hyper Carry):** Forte Circuit > Res. Liberation > Res. Skill > Basic Attack > Intro Skill
- **Key mechanics:**
  - **Umbra (0–100):** Filled by Basic Attacks (+33 per string), Skills (+40), and Intro (+33). When full → Heavy Attack activates Dark Surge state.
  - **Dark Surge:** Enhanced Basic Attacks, refreshed Skill (Lifetaker), Havoc DMG +20%, +25% CRIT Rate (S6), heals on BA5 (S3), +1 ER/s from Basics, enemy Havoc RES -10% (S4). Drains over time even off-field.
  - **Optimal Umbra setup:** Use Skill before going off-field (+40), then Basics (+33), then Intro on re-entry (+33) = 106 Umbra, enters Dark Surge immediately with full buffs.
  - **Dreamless+Ultimate combo:** Use Ultimate → immediately Echo (Dreamless) + swap-cancel. The "double Ultimate" — defines Rover's burst identity.
- **Sequences (all free):**
  - S1: Skill DMG +30% | S2: Skill cooldown resets on Dark Surge entry — **extends DPS window significantly**
  - S3: Dark Surge BA5 heals 10% HP lost | S4: -10% enemy Havoc RES from Devastation/Liberation — **team buff**
  - S5: Dark Surge BA5 extra +50% hit | S6: Dark Surge CRIT Rate +25% — **massive, changes stat targets**
- **Teams:**
  - **Best:** Havoc Rover + Roccia + Shorekeeper/Verina
  - **Phrolova Team:** Phrolova + Havoc Rover + Danjin/Cantarella + Shorekeeper
  - **F2P:** Havoc Rover + Danjin + Sanhua + Shorekeeper/Verina
  - **Cantarella Alt:** Havoc Rover + Cantarella + Shorekeeper/Verina (extra heals only)
- **Rotation (Short Burst — Dual DPS):**
  Intro → Skill → Heavy: Devastation → Skill: Lifetaker (optional swap) → Ultimate → Echo: Dreamless (swap cancel) → Outro
- **Rotation (Medium Burst — Main DPS):**
  Intro → Skill → Heavy: Devastation → Basic P1–P5 (×2 chains) → Skill: Lifetaker → Ultimate → Echo: Dreamless (swap) → Outro
- **Rotation (Long Burst — max damage, hard):**
  Intro → Skill → Heavy: Devastation → Basic P1–P5 → Skill: Lifetaker → Basic P1–P5 → Ultimate → Basic P1–P5 → Echo: Dreamless (swap) → Outro
- **Notes:**
  - Free 5★ with free sequences. One of the best free characters in the game.
  - Dreamless+Ultimate = "double Ultimate" — uniquely powerful burst window.
  - Biggest weakness: long on-field time for Main DPS; poor AoE outside of nuke windows.
  - Dual DPS with Danjin (F2P) is one of the best budget teams in the game.
  - Emerald of Genesis (standard banner) is the best accessible weapon.

  Intro → Skill: Acrobatic Trick → Real Fantasy P1 → P2 → P3 → Ultimate → Echo (swap cancel) → Outro

  - CRIT Rate ≥70% is a hard requirement for max Liberation ATK buff — don't neglect this threshold.
  - Pero (the pet) is mentioned in virtually every Roccia guide. It's a major part of her character appeal.

### Phrolova — Main DPS / Sub-DPS (Havoc)
**Source:** IWinToLose Gaming — https://www.youtube.com/watch?v=TcuvDXnOy00
**Prydwen page last updated:** Patch 2.5 (review), Patch 3.0 (build/calcs), June 9 2026 (profile)
**Rarity/Weapon:** 5★ Rectifier
**Tier:** T0.5 Tower of Adversity | **T0 Whimpering Wastes**

- **Echo (BiS):** Nightmare: Hecate (12% Havoc DMG + 20% Echo Skill DMG in slot) | 3pc **Dream of the Lost** + 2pc **Havoc Eclipse** or **Midnight Veil**
  - Dream of the Lost (3pc): CRIT Rate +20% + Echo Skill DMG +35% — **EXCLUSIVE to Phrolova** (requires 0 Resonance Energy)
  - 2pc Havoc Eclipse or Midnight Veil: both give +10% Havoc DMG. Also works: Endless Resonance 2pc or Frosty Resolve 2pc.
- **Echo main stats:** 4-cost CRIT DMG > CRIT Rate | 3-cost Havoc DMG | 3-cost Havoc DMG | 1-cost ATK% | 1-cost ATK%
- **Weapons:**
  - BiS: Lethean Elegy R1 (Phrolova's sig — 100%) — ATK, CRIT Rate, Echo Skill DMG Amplification, DEF Ignore. Gap to next option is alarming. **PACKAGE DEAL: pull with Signature.**
  - 2nd: Stringmaster R1 (82%) | 3rd: Whispers of Sirens R1 (80.2%) | 4th: Rime-Draped Sprouts R1 (77.1%)
  - F2P: Cosmic Ripples R1 (72.4%) — best permanent option
  - Battle Pass: Radiant Dawn R5 (66.9%), Augment R5 (64.9%)
  - F2P 4★: Fusion Accretion R5 (64.1%), Jinzhou Keeper R5 (63.6%)
- **Stat targets (Level 90):**
  - HP: 15,000+ | DEF: 1,100+ | ATK: 2,000–2,500+
  - CRIT Rate: 60%+ (before Dream of the Lost adds 20%) | CRIT DMG: 215–260%+ (before Aftersound ramp)
  - ER: **100% ONLY — NEVER build ER substats** (she has 0 max Energy, ER is completely wasted)
  - Havoc DMG Bonus: 30–70%+
- **Substats priority:** CRIT Rate = CRIT DMG > ATK% > Skill ATK DMG% > flat ATK
- **Forte/Skill priority:** Res. Liberation > Basic Attack > Forte Circuit > Intro Skill > Res. Skill
- **Key mechanics:**
  - **Zero Resonance Energy:** Her Ultimate costs 0 Energy. Never build ER. She generates small Energy for teammates.
  - **Maestro state (24s):** Activated via Scarlet Coda (Forte Heavy, needs 6 notes + Compose state every 25s). Grants 120% ATK self-buff. Hecate attacks off-field.
  - **Volatile Notes (up to 6):** Strings (Basic P3/Enhanced Basic = stagger), Winds (Skill/Enhanced Skill = pull), Cadenza (Intro/Echo Skill via Inherent = stagger+pull). Notes determine Hecate's attack type.
  - **Aftersound (up to 24 stacks):** Each = +2.5% CRIT DMG. After cap, excess = +1% CRIT DMG more (up to +100%). Also boosts Scarlet Coda multiplier. Starts at 10 stacks in combat, ramps over time — she gets stronger the longer the fight.
  - **Hecate (off-field):** Auto-attacks once per second when Phrolova is off-field. When any character uses Echo Skill (up to 10 times per Maestro) → Enhanced Attack. This is the Cantarella synergy.
  - **Enhanced Intro:** Available after first Ultimate. Strong damage + ends Maestro (triggers final Hecate flurry).
  - **Scarlet Coda (Forte Heavy):** Also counted as Echo Skill. AoE pull + Havoc DMG. Aftersound stacks boost multiplier.
  - **S6 off-field bonus:** Enemy takes 40% more DMG from Hecate while Phrolova is off-field.
- **Sequences:**
  - S1: Enhanced Basic/Skill +80%; auto-fill 2 Cadenza notes (comfort) — **strong**
  - S2: Scarlet Coda DMG +75% + Aftersound +75%; casting Coda grants 14 Aftersound stacks — **significant**
  - S3: Echo Skill Amplified +80%; Cadenza notes give enemy ATK -20% debuff — **great**
  - S4: Echo Skill → team Attribute DMG +20% for 30s — **team-wide buff**
  - S5: Entering Maestro → 4s Stagnation field + DMG Taken -30% in Maestro | S6: transformative off-field multipliers
  - *Key stopping points: S2, S3, S6*
- **Outro:** 20% Havoc DMG Amplification + 25% Heavy ATK DMG Amplification for 14s (+ 2 instant Hecate Enhanced Attacks if still in Maestro)
- **Teams:**
  - **BiS:** Phrolova + Lucilla + Cantarella + Qiuyuan
  - **Standard Best:** Phrolova + Cantarella + Roccia/Danjin/Qiuyuan + Shorekeeper
  - **Alt:** Phrolova + Sigrika + Roccia/Danjin + Qiuyuan/Shorekeeper
  - **Dual DPS (Jiyan/Galbrena/Phoebe):** Phrolova + Jiyan/Galbrena + Shorekeeper/Verina
  - **F2P:** Phrolova + Danjin + Shorekeeper/Verina + Havoc Rover/Buling
- **Rotation (Opener — no Intro):**
  Switch in (skips BA1) → Basic P2 → P3 → Forte: Basic/Skill → Skill → Forte: Basic/Skill → Basic P1–P3 → Forte: Basic/Skill → Heavy: Scarlet Coda → Ultimate → Outro
- **Rotation (Loop — Enhanced Intro available):**
  Intro: Suite of Immortality → Basic P3 → Forte: Basic/Skill → Skill → Forte: Basic/Skill → Basic P1–P3 → Forte: Basic/Skill → Heavy: Scarlet Coda → Ultimate → Outro
  *Echo best timed after second Forte Enhanced attack. Boss = use Forte: Basic; Multi-enemy = use Forte: Skill.*
- **Notes:**
  - **#1 Havoc DPS with Signature. Without Signature, pull Camellya instead.**
  - Dream of the Lost echo set is **exclusively hers** — can't share with teammates (requires 0 max Energy).
  - **Best wave-clear in the game (T0 WW)** — Scarlet Coda AoE pull, Hecate stagger, excellent multi-target coverage.
  - First rotation always weaker due to Aftersound ramp — she scales the longer a fight goes on.
  - Deals roughly half damage on-field, half off-field via Hecate (who continues attacking while others play).
  - Prydwen's review famously explains her kit using actual music theory (treble clef, waltz time signatures) because the kit is that dense.

### Chisa — Support / Negative Status Specialist (Havoc)
**Source:** IWinToLose Gaming — https://www.youtube.com/watch?v=2oxhbOqbtnw
**Prydwen page last updated:** Patch 2.8, May 24 2026 (profile)
**Rarity/Weapon:** 5★ Broadblade
**Tier:** T0 Tower of Adversity | T0.5 Whimpering Wastes (as Support)

- **Echo (BiS):** Reminiscence: Threnodian - Leviathan (12% Havoc DMG + 12% Liberation DMG in slot; extra DMG if target has Havoc Bane) | 3pc **Thread of Severed Fate** + 2pc **Havoc Eclipse** or **Midnight Veil**
  - Thread of Severed Fate (3pc): ATK +20% + Liberation DMG +30% for 5s when applying Havoc Bane (essentially permanent at 1 Bane per 2s)
  - Alt 2pc: Endless Resonance, Moonlit Clouds, or Empyrean Anthem
- **Echo main stats:** 4-cost CRIT DMG > CRIT Rate | 3-cost Havoc DMG > ATK% | 3-cost Havoc DMG | 1-cost ATK% | 1-cost ATK%
- **Weapons:**
  - BiS: Kumokiri R1 (100%) — Liberation DMG + 24% All-Type DMG Bonus for Negative Status applicators. Near-essential for team buff role.
  - 2nd: Wildfire Mark R1 (90.1%) — personal damage only | 3rd: Ages of Harvest R1 (84.8%)
  - 4th: Verdant Summit R1 (84.3%) | 5th: Radiance Cleaver R1 (83.9%) — best permanent option
  - F2P: Lustrous Razor R1 (81.8%) — standard banner, ATK + ER + Liberation DMG; great F2P choice
  - Craftable: Meditations on Mercy R5 (73.5%) — Rinascita craftable, best no-gacha 4★
  - Battle Pass: Autumntrace R5 (73.6%)
- **Stat targets (Level 90):**
  - HP: 15,000+ | DEF: 1,100+ | ATK: 2,000–2,500+
  - CRIT Rate: 65–80%+ | CRIT DMG: 210–255%+
  - ER: 125%+ | Havoc DMG Bonus: 40–70%+
- **Substats priority:** ER (until satisfied) > CRIT Rate = CRIT DMG > ATK% > Liberation DMG% > flat ATK
- **Forte/Skill priority:** Forte Circuit > Res. Liberation > Basic Attack > Res. Skill > Intro Skill
- **Key mechanics:**
  - **Unseen Snare:** Applied by Skill, Serrated Loop (range), Hold Dodge Counter, or lock-on. While active: allies with Thread of Bane ignore 18% DEF; Chisa applies Havoc Bane every 2s.
  - **Havoc Bane:** 1 stack per 2s (or 1s at S4). Max 6 stacks = 12% DEF Shred.
  - **Thread of Bane:** 18% DEF Ignore for any teammate that applies Negative Status or deals Negative Status DMG. **Does nothing for non-Negative Status characters.**
  - **Signature (Kumokiri):** 24% All-Type DMG Bonus for Negative Status applicators only. **Useless for non-Negative Status characters.**
  - **Outro:** Increases max Negative Status/Electro Rage stacks by 3 on hit (15s). Teammates with Thread of Bane spread it to other enemies.
  - **Ring of Chainsaw (0–100):** Filled by Basic Attacks + Liberation (+40) + Intro (+20). Full = can cast Serrated Loop → enters Chainsaw Mode.
  - **Chainsaw Mode:** Sawring - Blitz (Liberation DMG) → Sawring - Eradication (massive nuke + team shield). Eradication DMG scales with Ring of Chainsaw consumed.
  - **Liberation:** Heals team + grants 40 Ring of Chainsaw + enters Woven Myriad - Convergence (15s: Chainsaw attacks +120% DMG multiplier).
  - **Death Snip extra hit:** Press BA again 1–2 times during Death Snip for extra DMG and healing.
- **Sequences:**
  - S1: Immune to interrupt in Chainsaw; Unseen Snare → ATK +30% + fixed 61,803 Havoc DMG hit (reduces target to 61.80% HP max, once per target) — **very strong spike**
  - S2: 10% Havoc RES ignore + team with Thread of Bane gets 50% All-Attribute DMG Bonus — **massive team buff**
  - S3: Chainsaw attacks +120% DMG (stacks with Woven Myriad = 240%) + enemy ATK -20% debuff — **transformative**
  - S4: Havoc Bane applies every 1s | S5: Liberation +100% DMG + Glide costs less
  - S6: Fatal blow immunity in Chainsaw + 30% Amplified Negative Status DMG + 40% increased DMG to Chisa's attacks
- **Teams:**
  - **Best:** Aemeath + Denia + Chisa (Fusion Burst Neg. Status team)
  - **Hiyuki Team:** Hiyuki + Lynae + Chisa
  - **Cartethyia Team:** Cartethyia + Ciaccona + Chisa (only better than Aero Rover WITH Signature; use Skyfall Severance to convert Havoc Bane to Erosion)
  - **Phoebe Expert:** Phoebe + Spectro Rover + Ciaccona + Chisa (niche, high investment only)
- **Rotation (Opener — no Intro):**
  Skill: Eye of Unraveling → Basic: Rending Lunge (Echo cancel, then Ultimate) → Ultimate → Basic P2 → Rending Lunge → Death Snip Full (Skill cancel) → Skill: Serrated Loop → Sawring Blitz P2 → P3 → Falltone (auto) → Eradication (Swap) → Outro
- **Rotation (Loop):**
  Intro → Basic P2 → Rending Lunge → Death Snip Full (Ultimate cancel) → Ultimate → Skill: Serrated Loop → Sawring Blitz P2 → P3 → Falltone (auto) → Eradication (Swap) → Outro
  *Echo: cast right before Ultimate to cancel its animation.*
- **Notes:**
  - **Only functional in Negative Status teams.** No generalist value; Baizhi outclasses her as generic support.
  - **Currently in "Roccia situation":** Best at one specific team (Cartethyia + Ciaccona) but only marginally beats free Aero Rover there, and ONLY with Signature.
  - **Meta prognosis:** Strong future potential if more Negative Status DPS are released. Recommend waiting for rerun unless you play Cartethyia or really like her.
  - DEF reduction quirk: 18% DEF Ignore (character-side) + 12% DEF Shred (enemy-side) don't simply add; 30% of either type alone would be more effective than this split.
  - Kumokiri's team buff requires Negative Status application — completely dead for Aero Rover (who applies none) in a Cartethyia team. This is the critical caveat.
  - Unique Chainsaw Mode mechanics (Ring gauge, Jetstream, Bane/Snare system) require dedicated kit explanation in a guide video.
