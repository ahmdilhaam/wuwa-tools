### Calcharo — Main DPS (Electro)
**Source:** Prydwen.gg (updated Patch 2.6, profile updated June 2026)
- **Echo:** Nightmare: Thundering Mephis | Void Thunder (5pc)
  - 4-cost main stat: CRIT Rate or CRIT DMG
  - 3-cost: Electro DMG × 2 (second slot: ATK% if Electro DMG unavailable)
  - 1-cost: ATK% × 2
- **Weapons:**
  - BiS: Wildfire Mark (R1) — Lupa's sig; buffs Liberation DMG (100.72%)
  - #2: Lustrous Razor (R1) — ATK 587, ATK% 36.4% (100%)
  - #3: Ages of Harvest (R1) — ATK 587, CRIT Rate 24.3% (98.37%)
  - #4: Verdant Summit (R1) — ATK 587, CRIT DMG 48.6% (96.69%)
  - Best 4-star: Autumntrace (R5) — ATK 412, CRIT Rate 20.2% (94.25%)
  - F2P budget: Waning Redshift (R5) — ATK 462, ATK% 18.2% (83.29%)
- **Stats (Level 90, S0):**
  - ATK: 1800–2300+
  - ER: 120–160%+ (lower end: Lynae+Shorekeeper; higher end: Xiangli Yao+Shorekeeper quickswap; S1 reduces by ~20%)
  - CRIT Rate: 60–80%+
  - CRIT DMG: 215–280%+
  - Electro DMG Bonus: 40–70%+
- **Forte priority:** Forte Circuit > Res. Liberation > Res. Skill > Intro Skill > Basic Attack
- **Substats:** Energy Regen (until satisfied) > CRIT Rate = CRIT DMG > ATK% > ATK = Liberation DMG%
- **Teams:**
  - Best Hypercarry: Calcharo + Lynae + Yinlin + Mornye (Mornye best with Lynae) / Shorekeeper / Verina
  - Budget: Calcharo + Jianxin + Shorekeeper / Verina (incompatible with Swap Cancels)
- **Rotation:**
  1. Warm-up Option 1: Basic P1 → Skill P1 → Basic P2 → Skill P2 → Basic P3 → Basic P4 → Skill P3 → Heavy ATK Mercy (optional swap-cancel)
  2. Warm-up Option 2 (safe): Skill P1 → Skill P2 → Skill P3 → Heavy ATK Mercy
  3. Optimized Burst (dash-cancel): Echo (pre-cast swap-cancel) → Intro → Ultimate → Death Messenger (optional swap-cancel) → Hounds Roar P1 → P2 (Dash Cancel) → P1 → P2 (Dash Cancel) → P1 → Death Messenger → repeat → Death Messenger → Outro
  4. Target: 3 Death Messengers minimum; 4 is theoretical (considered near-impossible consistently)
- **Sequences:**
  - S1: Skill restores +10 Resonance Energy once per 20s — Medium value; reduces ER requirements
  - S2: +30% Resonance Skill DMG Bonus after Intro for 15s — Medium value
  - S3: +25% Electro DMG Bonus during Deathblade Gear state — Good value
  - S4: +20% Electro DMG Bonus for all team members after Outro for 30s — Medium team value
  - S5: Intro deals +50% DMG — Low value
  - S6: Summons 2 Phantoms during Death Messenger — High value
- **Notes:**
  - Hardest rotation in the game. Death Messengers have long wind-up animations prone to interruption.
  - Swap-canceling Death Messengers gains consistency but forfeits Yinlin Outro buffs (trade-off).
  - Only realistic meta partner is Yinlin (limited 5-star). Standard banner DPS.
  - Near-zero AoE capability. Tier 4 DPS at casual level.
  - Xiangli Yao's Ultimate timestop can help land extra Death Messengers in quickswap.

### Yinlin — Hybrid / Sub-DPS (Electro)
**Source:** Prydwen.gg (updated Patch 3.2, profile updated June 2026)
- **Echo:** Impermanence Heron | Moonlit Clouds (5pc) [PRIMARY — best for team DPS]
  - Alternative: Nightmare: Tempest Mephis | Empyrean Anthem (5pc) [personal damage]
  - 4-cost main stat: CRIT DMG > CRIT Rate
  - 3-cost: Electro DMG × 2
  - 1-cost: ATK% × 2
- **Weapons:**
  - BiS sig: Stringmaster (R1) — ATK + CRIT Rate + DMG Bonus (100%)
  - #2: Whispers of Sirens (R1) — CRIT DMG + ATK + Basic DMG Bonus (96.70%)
  - #3: Rime-Draped Sprouts (R1) — CRIT DMG + ATK (96.30%)
  - #4: Lethean Elegy (R1) — CRIT Rate + high base ATK (94.80%)
  - Permanent: Cosmic Ripples (R1) — ATK + Energy Regen (90.00%)
  - F2P 4-star (Battle Pass): Augment (R5) — ATK + CRIT (88.10%)
  - F2P no-gacha: Jinzhou Keeper (R5) — ATK buffs (78.10%)
- **Stats (Level 90, S0):**
  - ATK: 2000–2400+
  - ER: 128%+ (estimated in Xiangli Yao + Shorekeeper team)
  - CRIT Rate: 45–65%+ (before Inherent Skill passive +15% CRIT Rate)
  - CRIT DMG: 255–280%+
  - Electro DMG Bonus: 30–70%+
- **Forte priority:** Forte Circuit > Res. Liberation > Res. Skill > Basic Attack > Intro Skill
- **Substats:** Energy Regen (until breakpoint) >= CRIT Rate = CRIT DMG > ATK% > Flat ATK = Resonance Skill DMG%
- **Teams:**
  - Iuno Hypercarry: Iuno + Yinlin + Shorekeeper + Rover (Aero)
  - Jinhsi: Jinhsi + Yinlin + Shorekeeper / Verina
  - Electro Carry: Augusta / Xiangli Yao / Calcharo + Yinlin + Shorekeeper / Verina
- **Rotation:**
  1. Intro → Basic P4 (optionally swap-cancel) → Skill: Magnetic Roar → Heavy Attack → Skill: Lightning Execution (cancel Heavy ATK endlag) → Ultimate (as Yinlin lands) → Basic P1 → Forte Heavy: Chameleon Cipher → Outro
  2. Echo: use right after Chameleon Cipher, swap-cancel into Outro
- **Sequences:**
  - S1: +70% DMG on Magnetic Roar and Lightning Execution — High value
  - S2: +5 Judgment Points and Resonance Energy per Electromagnetic Blast hit — Good value; smoother rotation
  - S3: +55% to Judgment Strike DMG multiplier — High value
  - S4: +20% ATK for entire team on Judgment Strike hit for 12s — Very high value (team buff)
  - S5: +100% DMG to Thundering Wrath on marked targets — High value
  - S6: Furious Thunder coordinated attacks on Basic Attack hits — Extremely high value
- **Notes:**
  - Do NOT run Void Thunder in Hybrid role — Moonlit Clouds + Impermanence Heron is correct.
  - Do NOT play as Main DPS — performance drops drastically vs Hybrid role.
  - High signature weapon reliance compared to most limited 5-stars. Cosmic Ripples is only ~90%.
  - Outro: 20% Electro DMG Deepen + 25% Liberation DMG Deepen for 14s — crucial for Calcharo/Xiangli Yao.
  - Chameleon Cipher is swap-cancellable at end of rotation.
  - Outclassed by Zhezhi in Jinhsi teams, but remains close second.

### Yuanwu — Support (Electro)
**Source:** Prydwen.gg (updated Patch 2.1, profile updated January 2026)
- **Echo:** Fallacy of No Return | Rejuvenating Glow (5pc) [primary support build]
  - Alternative: Impermanence Heron | Moonlit Clouds (5pc) [second support set option]
  - 4-cost main stat: CRIT DMG > CRIT Rate (if building damage)
  - 3-cost: Electro DMG > DEF%
  - 1-cost: DEF% × 2
- **Weapons:**
  - Support role (required): Originite: Type IV (R5) — ATK 300, CRIT DMG 40.5% [3-star; enables Rejuvenating Glow via self-heal]
  - Damage role: Amity Accord (R5) — ATK 337, DEF% 61.5% (best damage option)
  - F2P damage: Guardian Gauntlets (R5) — ATK 300, DEF% 38.4%
  - F2P energy: Gauntlets of Voyager (R5) — ATK 325, DEF% 30.7%
- **Stats (Level 90, S6 — support role):**
  - HP: 13000+
  - DEF: 1800+
  - ATK: 1200+
  - CRIT Rate: 60%+ (if building damage; not required for support)
  - CRIT DMG: 250%+ (if building damage)
  - ER: 100% (meta Jinhsi team does not require his Liberation)
  - Electro DMG Bonus: 30–60%+
- **Forte priority:** Res. Liberation > Res. Skill > Forte Circuit > Intro Skill > Basic Attack
- **Substats:** Energy Regen (until breakpoint) >= CRIT Rate = CRIT DMG > DEF% > Flat DEF
- **Teams:**
  - Best (only meta): Jinhsi + Yuanwu + Shorekeeper / Verina
    (Run Yuanwu on Rejuvenating Glow; third member on Moonlit Clouds)
- **Rotation:**
  1. Echo → Intro (if available) → Skill: Place Thunder Wedge → Ultimate (detonates Wedge) → Forte: Rumbling Spark → Skill: Place Thunder Wedge → Outro (if available) → Skill: Place Wedge as needed
  2. Keep Thunder Wedge always active and within range of current target enemy
  3. No fixed tight rotation — maintain Wedge, use Ultimate when available
- **Sequences:**
  - S1–S5: All very low value in support role; personal damage is negligible
  - S6: +32% DEF to all nearby team members for 3s — Low value overall
  - Prydwen calcs show S0 through S6 perform identically in support role — no investment needed
- **Notes:**
  - Free character. Needs zero investment to perform his role.
  - Originite: Type IV (3-star weapon) enables Rejuvenating Glow via Basic Attack self-heal proc.
  - Only one meta use case: Jinhsi Forte stack generation via highest Coordinated Attack frequency in game.
  - Outro provides Vibration Strength depletion (stagger bar) — useful for boss fights.
  - Deals essentially zero personal damage; only value is stack generation and team ATK buff from Rejuvenating Glow.

  - Press Resonance Skill at least once before Ultimate to trigger Void Thunder 5pc set bonus.
  - Two Deduction uses pre-Ultimate maximizes Void Thunder stacks to ×2 (optimal setup).
  - Ultimate timestop is slightly longer than normal — exploitable in quickswap for extra attack windows.
  - Was obtainable for free at patch 1.2 release.

### Augusta — Main DPS (Electro)
**Source:** Prydwen.gg / Wutheringlab / Game8 (cross-referenced)
- **Echo:** The False Sovereign | Crown of Valor (5pc)
  - The False Sovereign: 12% Electro DMG + 12% Heavy DMG Bonus passively in main slot; auto-summons on Intro trigger
  - Crown of Valor: on Shield gain, grants 6% ATK + 4% CRIT DMG per stack, up to 5× (total: 30% ATK + 20% CRIT DMG); Augusta is the only character who consistently stacks this to maximum via her shield mechanic
  - 4-cost main stat: CRIT Rate or CRIT DMG
  - 3-cost: Heavy DMG Bonus or Electro DMG × 2
  - 1-cost: ATK% × 2
- **Weapons:**
  - BiS sig: Thunderflare Dominion — Augusta's signature, best personal + team damage
  - #2: Verdant Summit (R1) — ATK 587, CRIT DMG 48.6% (~6–7% behind sig)
  - #3: Ages of Harvest (R1) — ATK 587, CRIT Rate 24.3%
  - #4: Lustrous Razor (R1) — ATK 587, ATK% 36.4%
  - Best 4-star: Autumntrace (R5) — ATK 412, CRIT Rate 20.2%
  - F2P budget: Waning Redshift (R5) — ATK 462, ATK% 18.2%
- **Stats (Level 90):**
  - ATK: 2100+
  - ER: ~120% (comfortable threshold for Liberation rotation)
  - CRIT Rate: 60–80%+
  - CRIT DMG: 220–250%+ (target ~250% with good rolls)
- **Forte priority:** Res. Liberation > Forte Circuit > Basic Attack > Res. Skill > Intro Skill
  - Liberation contributes ~60% of total damage; Forte ~22%; Normal Attacks ~14%
- **Substats:** CRIT Rate = CRIT DMG > ATK% > Energy Regen (to threshold) > Flat ATK
- **Teams:**
  - Best: Augusta + Iuno + Shorekeeper / Verina (Iuno provides ~90% DMG increase: 40%+50%)
  - Alternative: Augusta + Yinlin + Shorekeeper / Verina
  - Alternative: Augusta + Rebecca + Shorekeeper / Mornye / Verina
  - Budget: Augusta + Mortefi + Shorekeeper / Verina
- **Rotation:**
  1. Wait ~4s (passive energy build) → Skill → Heavy Attacks → Liberation 1 (timestop Ultimate) → Heavy Attacks within timestop → Charged Skill (Forte activation) → Liberation 2 → Echo (swap-cancel) → Outro
  2. Key: Liberation creates timestop allowing rapid heavy attack sequence without enemy interruption
- **Sequences:**
  - S1: Improves Forte Heavy multiplier — Medium value
  - S2: Energy restoration on mechanic proc — Medium value; smooths rotation
  - S3: Liberation scaling increase — High value
  - S4: Team Liberation DMG Bonus buff — Very high value
  - S5: Forte enhancements — High value
  - S6: Major multiplier increases — Extremely high value
- **Notes:**
  - Crown of Valor is effectively Augusta-exclusive; she uniquely stacks it to 5× via her kit's shield generation.
  - CRITICAL: Never swap between characters during Augusta's Outro — doing so loses Majesty points and breaks the buff cycle.
  - Iuno is her best support by a wide margin in current meta (3.2+).
  - Tier 3 DPS (Tower of Adversity) — competitive in meta with correct team composition.
