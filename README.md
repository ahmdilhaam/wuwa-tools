# WuWa Tools

Damage calculator and build library for Wuthering Waves. The site is in Indonesian.

## Features

- **Damage calculator** — calculate a single hit or compare two builds side by side. Pick a resonator, skill, and hit to fill in the official motion value, choose from 159 enemies, and see how each factor (bonus, DEF, RES, crit) changes the result.
- **Resonators** — 60 characters with build recommendations (echoes, weapons, stats, teams, rotation), motion values per skill level, and sequences S1–S6.
- **Echo sets, weapons, mechanics** — sonata set bonuses, weapon stats and passives, general build rules, and substat roll ranges.

## Data

Game data (skills, weapons, sonata sets, enemies) comes from [encore.moe](https://encore.moe). Build recommendations are compiled from community guides such as Prydwen, Game8, and Wutheringlab.

Want to run it locally or update the data? See [DEVELOPMENT.md](DEVELOPMENT.md).
